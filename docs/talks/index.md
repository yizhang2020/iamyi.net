# Talks

These are **invited presentations** built from publicly disclosable material: open-source ideas, published practice, and general non-secret security thinking. They are not based on confidential customer work, private vulnerability details, or internal proprietary data.

Each talk page includes an **on-page slide viewer** (Previous / Next) plus a PowerPoint download. Essays and minibooks remain the place for deeper written treatment of the same themes.
