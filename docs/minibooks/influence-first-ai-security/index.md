# Influence-First AI Security

**Version 0.9.2** · 2026-09-20  
**Guiding statement:** Trace influence. Bound authority.

This minibook is a book-length treatment of influence-first analysis: making influence a first-class concern wherever AI participates in decisions, then following consequences into connected software, services, and human workflows.

Edits here are for iamyi.net only. They are not synced back to any upstream repository.
